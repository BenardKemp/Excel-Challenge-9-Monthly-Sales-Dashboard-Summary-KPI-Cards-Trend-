# SolveWithExcel – Challenge #9
## Monthly Sales Dashboard Summary (KPI Cards + Trend)

This challenge focuses on transforming raw monthly sales data into a compact, decision-ready dashboard summary. You will calculate key performance indicators (KPIs) and add a visual trend indicator to answer business questions at a glance.

This pattern is commonly used in executive summaries and management reports.

Difficulty
Intermediate

Estimated Time
30–40 minutes

# The Problem

Tables show data—but dashboards communicate insight.

Your task is to:

Extract the most recent sales figures
Compare current vs previous performance
Summarize results using KPI-style metrics
Add a trend indicator for quick context

All calculations must be done using Excel formulas.

# Dataset

MonthlySales columns:

Month (date-formatted)
Sales

The dataset spans six consecutive months and represents a typical reporting window.


# Your Tasks

## 1. Build KPI Metrics

On a Dashboard sheet, calculate:

Latest Month Sales
Previous Month Sales
Month-over-Month Change (%)
6-Month Average Sales

All values should update automatically.

## 2. Add Status Indicator

Create a Status label based on Month-over-Month change:

"Up" if positive
"Down" if negative
"Flat" if zero

## 3. Add Trend Sparkline

Insert a line sparkline showing the 6-month sales trend inside a single cell.

# Requirements

Use Excel formulas only
No Pivot Tables
KPIs must update dynamically
